Integrantes y responsabilidades: Iván Moscovich Levi y Juan Manuel Sabathie Lopez, ambos hicimos parte del proyecto tanto en una computadora ambos como dos computadoras diferentes.
Temática: App basada en spotify
Arquitectura: Usamos postgress para la BD y Deezer como api para la musica
Instalación local: Correr postgress en devandroid, iniciar la BD(todos los archivos), clonar proyecto y npm i para despues npm start. Antes de eso hacer el .env
Comandos para correr el proyecto: npm i, npm start
API externa: Deezer api para la musica(Todavia no la probamos).
